# CFO VICOMER

Pipelines financieros y de reporting del Grupo VICOMER (Ecuador · Colombia · Costa Rica) sobre Odoo y Perseo.

- **Empieza por [`CLAUDE.md`](CLAUDE.md)**: fuentes, reglas, pipelines y estado de migración a la nube.
- Arranque en la nube: `source cloud/setup.sh && python3 cloud/check_red.py`
- Credenciales: solo variables de entorno (plantilla en `.env.example`). Nada sensible entra al repo.
